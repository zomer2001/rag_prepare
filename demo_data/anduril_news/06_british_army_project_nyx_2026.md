# 英国陆军将 Anduril UK 纳入 Project NYX 下一阶段

- 发布日期：2026-05-15
- 来源机构：Anduril Industries
- 原始来源：https://www.anduril.com/news/british-army-down-selects-anduril-uk-to-build-land-autonomous-collaborative-platforms
- 文档类型：基于公开新闻的中文整理摘要，不是原文转载

## 事件摘要

英国国防部将 Anduril UK 选入 Project NYX 下一阶段。该项目希望开发能够与英国陆军
AH-64E Apache 攻击直升机协同作战的自主协作平台，用于侦察、目标获取和打击任务。

## 关键事实

- NYX 关注以无人或自主平台增加作战规模，同时降低有人平台暴露风险。
- Anduril 方案强调 collaborative mission autonomy，即多平台协同任务自主。
- 自主平台被设计为可与 Apache 配合，并管理成群的 launched effects。
- 方案计划吸收商业垂直起降市场的混合电推进技术。
- 英国陆军把项目与 2030 年前提升杀伤力及未来有人、可复用、消耗型平台组合联系起来。

## 涉及实体与关系

英国国防部负责项目选择；英国陆军提出作战需求；Anduril UK 参与 Project NYX；
自主协作平台与 AH-64E Apache 配合作战；NATO 被视为相关能力的潜在受益体系。

## 分析线索

Project NYX 展示 Anduril 向欧洲陆战和有人—无人协同领域扩展。其核心竞争力仍是把
自主软件、模块化平台和快速工程结合，而不是只销售单一型号无人机。
