# AWS 将 Anduril 列为国家安全与国防领域首选边缘计算提供商

- 发布日期：2026-06-30
- 来源机构：Anduril Industries
- 原始来源：https://www.anduril.com/news/aws-names-anduril-a-preferred-edge-provider-for-national-security-and-defense
- 文档类型：基于公开新闻的中文整理摘要，不是原文转载

## 事件摘要

Amazon Web Services（AWS）将 Anduril 列为面向国家安全客户的首选边缘计算提供商。
双方计划把 AWS 的计算、存储、网络、API 和生成式人工智能服务带到通信不稳定、与
云端断开或存在对抗的前沿环境。

## 关键事实

- 双方推出集成 AWS Outposts 的 Menace-I 可部署数据中心。
- Menace-I 可装载 AWS Outposts 计算机架，并通过卡车、铁路、空运或直升机吊运。
- 公开材料称，两名非专业人员可以在十分钟以内完成系统部署。
- 系统可按任务扩展为单机架或多机架配置，并支持从非密到敏感隔离信息等级的需求。
- Anduril 表示，Menace-I 已积累超过 50,000 小时的全球部署使用时间。

## 涉及实体与关系

AWS 与 Anduril 建立首选边缘提供商合作；AWS Outposts 被集成到 Anduril 的
Menace-I；Menace-I 服务于国家安全、指挥控制、情报、后勤、任务规划和自主系统等
计算需求。

## 分析线索

合作将 Anduril 的硬件部署能力与 AWS 的商业云生态结合，反映国防软件架构正尝试把
公有云能力延伸至战术边缘，而不是只在固定数据中心运行。
